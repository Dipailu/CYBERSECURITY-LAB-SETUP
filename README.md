
# CYBERSECURITY LAB SETUP

## Project Overview

This project focuses on setting up a virtual cybersecurity laboratory using Oracle VM VirtualBox and Kali Linux.

The main purpose of this lab is to create a virtual environment where I can learn and practice basic networking concepts and cybersecurity techniques safely.

The project includes configuring a Kali Linux virtual machine, establishing a virtual network using NAT Network, assigning a manual IPv4 address, and testing network connectivity.

## Project Objectives

- Install and run Kali Linux in Oracle VM VirtualBox.
- Configure a virtual NAT Network.
- Configure manual IPv4 network settings.
- Understand IP addresses, subnet masks, gateways, and DNS.
- Test Internet connectivity using the ping command.
- Verify web access using Firefox.
- Document the entire laboratory setup with screenshots.

## Tools and Technologies

- Oracle VM VirtualBox
- Kali Linux
- Windows Host Operating System
- Firefox Web Browser
- VirtualBox NAT Network
